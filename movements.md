## Quick Pattern Reference
| Pattern | Primary movers | Examples |
|---|---|---|
| Squat | Quads, glutes | Front squat, wall ball |
| Hinge | Glutes, hamstrings, back | Deadlift, KB swing |
| Lunge | Quads, glutes, balance | Walking lunge, step-up |
| Vertical push | Shoulders, triceps | Press, HSPU |
| Horizontal push | Chest, triceps | Push-up, bench |
| Vertical pull | Lats, biceps | Pull-up, rope climb |
| Horizontal pull | Upper back, rear delts | Ring row, bent-over row |
| Olympic | Full-body power | Clean, snatch |
| Core / midline | Abs, spinal erectors | T2B, GHD sit-up |
| Mono | Cardio | Run, row, bike |
| Carry | Grip, trunk, legs | Farmer, sled |

## Notes for programming
- Mix patterns across the week: avoid stacking the same pattern/fatigue on consecutive days.
- Balance push:pull (roughly 1:1 or more pull).
- Technical skills (Olympic lifts, gymnastics) go early in the session when fresh.
- Scale by swapping to an easier variation in the same pattern (e.g., pull-up → ring row).
